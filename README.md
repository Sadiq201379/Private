# منصة مدرسة البهجة الأهلية — تجربة مجانية على Render

## المتطلبات
حساب GitHub وحساب Render.com. ارفع ملفات المشروع (وليس الملف المضغوط) إلى مستودع GitHub **خاص**. لا ترفع أي قاعدة بيانات أو كلمات مرور.

## خطوات النشر
1. فك ضغط ZIP على الكمبيوتر. أنشئ مستودع GitHub جديدًا (Private)، وارفع محتويات مجلد المشروع إلى جذر المستودع: `app.py`, `wsgi.py`, `render.yaml`, `requirements.txt`, ومجلد `static`.
2. سجّل الدخول إلى https://dashboard.render.com ثم اختر New > Blueprint، واربط حساب GitHub وحدد المستودع.
3. سيتعرف Render على `render.yaml`. عند مطالبتك بـ `ADMIN_PASSWORD` ضع كلمة مرور طويلة وفريدة لا تقل عن 12 حرفًا. **لا تضعها في GitHub أو في ملفات المشروع.**
4. اضغط Apply/Deploy وانتظر اكتمال البناء. افتح عنوان `https://bahjah-school-demo-...onrender.com` الذي يعرضه Render في لوحة الخدمة (قد يختلف الاسم).
5. سجّل الدخول باسم `admin` وكلمة المرور التي أدخلتها. أنشئ حسابات **وهمية للتجربة فقط**، ثم أضف درسًا تجريبيًا وجرب تسجيل الدخول كطالب.

## مهم جدًا: حدود الاستضافة المجانية
- خطة Render المجانية قد تتوقف عن العمل عند الخمول وتحتاج وقتًا للاستيقاظ.
- **ملفات SQLite المخزنة على القرص المجاني مؤقتة** وقد تضيع عند إعادة النشر أو إعادة التشغيل؛ لهذا لا تستخدم هذه النسخة لحفظ أي بيانات حقيقية، ولا تُدخل أسماء طلاب حقيقيين أو معلومات حساسة.
- للاستخدام الفعلي، يلزم قاعدة بيانات دائمة خارجية، وتخزين احتياطي، ومراجعة أمان وخصوصية قبل استقبال الطلاب.
- المزايا الحالية: تسجيل الدخول، إضافة الطلاب والمعلمين، الدروس والواجبات وروابط الحصص، وتسليم الإجابات النصية. لا تتضمن بثًا مباشرًا داخليًا أو اختبارات مؤتمتة أو شهادات.
- الأسعار والحصص المجانية وسياسات Render قابلة للتغيير، فتحقق من صفحة التسعير قبل الإنشاء.

## تشغيل محلي على Windows
```
py -m pip install -r requirements.txt
set ADMIN_PASSWORD=YourStrongUniquePasswordHere
set SECRET_KEY=YourLongRandomSecretHere
py -m waitress --listen=127.0.0.1:8080 wsgi:app
```
افتح http://127.0.0.1:8080
